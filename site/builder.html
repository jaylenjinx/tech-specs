4Fixtures

Calibrate the stage, then fix anything the reader got wrong
  1. Calibrate: press Mark DSE, then click the downstage edge at stage right and at stage left. The stage width from step 1 sets the scale.
  2. Check bars: fixtures in the same row are grouped into a bar. Rename bars, set how far upstage (m) and the trim, or press Regroup after moving fixtures.
  3. Fix fixtures: drag to move. Click one to change its ID or type. Pick an unplaced patch ID and click the plot to add it. Red = not in the patch, dashed orange = the same ID twice.
Load a plot in step 3, or an MVR in step 2.

5Preview and export

Adding it to the site

  1. Download the zip and unzip it in the tech-specs repo folder. It adds site/venues/<id>.json, the plot image in site/img/, and an updated site/venues/index.json.
  2. Commit and push. GitHub Pages redeploys and the venue appears as a new tab.

Preview uses the real site page with your draft added, so what you see is what will publish. Save project keeps the plot image and every correction, so you can come back and edit.
